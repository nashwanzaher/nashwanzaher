## 🚀 Currently building

### **[NASCO](https://github.com/nashwanzaher/nasco-landing)** — AI-native business operating system

The modern alternative to Odoo. CRM, sales, inventory, accounting, HR — connected by AI agents your team can talk to.

- 🧠 **AI-native from day one** — agents as first-class users with RBAC and audit
- 🔌 **MCP server** — every entity exposed to any AI agent
- ⚡ **Modern stack** — TypeScript everywhere, end-to-end type safety
- 🏗️ **Multi-tenant SaaS** — built to scale from day one
- 🌍 **Bilingual** — Arabic + English, RTL-first

> _"The operating system for companies that ship fast."_
